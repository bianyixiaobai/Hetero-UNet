## 模块二需要实现什么

当前`UNetResDecoder.forward`在每层将上采样解码特征与对应编码层skip拼接。模块二应研究多个编码尺度共同参与当前层解码，并保持原拼接接口和输出通道可兼容。

3.1必须明确：

1. 每个目标解码层使用哪些编码尺度，以及是否使用瓶颈；列出源张量和目标张量尺寸。
2. 各源的空间重采样、通道投影顺序及3D各向异性处理；避免把高通道特征全部提升到最高分辨率造成内存激增。
3. 动态权重的输入、形状、归一化维度和融合公式；说明权重是否随病例、位置、通道变化。
4. 融合结果如何接回原skip路径、如何初始化，以及训练和推理是否一致。
5. 独立skip门控与真正跨尺度交互的区别；前者可以作对照，不能直接替代多尺度主线。

以上事项的首版实现已在本机落实，具体公式和选取记录见实现文档。宽度上限16、相邻尺度及零残差初始化是预先设定的首版配置，不代表已调优；不因已有外部50例结果选择这些超参。

# 文档目录说明

更新日期：2026-10-29。项目总入口见[项目文档导航](../../项目文档导航.md)。

本目录保存随代码维护的实现说明、操作手册、日期执行记录，以及便于审查的小型配置和校验收据。权重、医学影像、完整预测、诊断数组和大压缩包在本机`output`及相应OSS归档中保存。

| 入口 | 用途 |

`stage2/session_日期/`只保留当次运行的小型原始证据。日期执行记录有独立时间范围，旧“保持开机”“只跑F”“C暂缓”等安排均按当时上下文阅读；当前安排查看F-aux执行记录和根目录工作计划。

维护时遵循：工作计划负责总体任务，入口负责导航，日期记录负责当次事实，原始收据负责核验。已签发收据、日志、JSON及备份包不回写成新状态。
